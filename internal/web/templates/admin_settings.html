File or environment only

Secrets and infrastructure values are never editable here and are never rendered in this page: session key, SMTP credentials, IGDB client ID/secret, TLS certificate and key paths, listen address, data directory, and database path. Change those in the config file or environment and restart the service.

The settings above are read on every request, so they take effect immediately. If registration mode is set to invite, an invite code is required.
